Tentang STRAMAS

STRAMAS adalah Web App pelacak aktivitas berlari tingkat lanjut. Menggunakan Geolocation API dan Leaflet Maps untuk memastikan pelacakan presisi. Didesain secara spesifik untuk memonitoring kecepatan, langkah, dan kalori secara akurat.
